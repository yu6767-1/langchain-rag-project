# 项目经历

## 项目一：RAG 企业级知识库问答系统

### 项目概述

独立开发了一个完整的 RAG（检索增强生成）企业级知识库问答系统。该系统允许企业上传内部文档（PDF、Word、Excel、CSV 等），自动向量化存储，然后员工可以通过自然语言提问，系统基于知识库内容给出有据可查的回答。

### 项目角色

独立全栈开发（前端 + 后端 + 数据库 + AI 集成）

### 技术架构

```
用户浏览器（Vue 3）
    ↓ HTTP / WebSocket
后端 API（FastAPI）
    ↓ LangChain RAG Chain
检索模块（ChromaDB 向量数据库）
    ↑ 文档向量化
文档处理（PDF/DOCX/XLSX/CSV/MD → 文本切分 → Embedding）
    ↓
大模型（阿里云通义千问 Qwen）
    ↓ 流式输出
用户得到回答
```

### 核心功能

1. **用户认证系统**：JWT Token 认证、注册登录、角色权限（admin/user）
2. **知识库管理**：多格式文档上传、自动向量化、文档状态追踪
3. **智能问答**：基于 RAG 的流式问答、引用来源标注
4. **多会话管理**：多用户多会话、历史记录持久化
5. **混合检索**：向量检索（语义）+ 关键词检索 + 加权融合

### 技术亮点

- 🚀 **混合检索**：向量检索 0.7 + 关键词匹配 0.3 加权融合，提升检索准确率
- 📝 **流式输出**：WebSocket 逐字推送，用户体验流畅
- 🔒 **安全防护**：XSS 过滤、bcrypt 密码加密、SQLAlchemy 防注入
- 🧪 **完整测试**：129 个 pytest 单元测试，覆盖正常/边界/异常情况
- ⚡ **性能优化**：检索缓存、模型选型（qwen-turbo）、Token 数优化

### 代码统计

- 后端：~2000 行 Python
- 前端：~1500 行 Vue/JS
- 测试：~2500 行 pytest
- 总计：~6000 行代码

### 项目收获

- 深入理解了 RAG 的完整工作流程
- 掌握了全栈开发的基本技能
- 学会了用 Mock 编写单元测试
- 理解了性能优化的基本思路

## 项目二：个人 AI 简历知识库

### 项目概述

基于同一个 RAG 系统，将自己的学习经历、技术能力、项目经验、成长思考整理成结构化的知识库文档，喂给 AI 系统。这样在和 AI 对话时，AI 能够基于我的个人知识库回答关于我的问题，相当于一个"AI 简历"。

### 项目价值

- 展示了对 RAG 系统的实际应用能力
- 将个人知识结构化、系统化
- 面向面试场景：面试官可以通过 AI 问答了解我的能力
