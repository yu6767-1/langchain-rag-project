# 学习路线

## 我的学习历程

我是从零基础开始学习编程和 AI 开发的。以下是我走过的完整学习路线。

## 第一阶段：编程基础（1-2 个月）

### Python 基础
- 变量、数据类型、控制流（if/for/while）
- 函数定义、参数传递、返回值
- 列表、字典、集合、元组
- 文件读写操作
- 异常处理（try/except）
- 面向对象编程（类、对象、继承、多态）

### 学习资源
- 廖雪峰 Python 教程
- Python 官方文档
- B 站 Python 入门视频

## 第二阶段：Web 开发基础（1 个月）

### 后端基础
- HTTP 协议基础（请求/响应、状态码、GET/POST）
- RESTful API 设计理念
- JSON 数据格式
- FastAPI 框架入门（路由、参数验证、依赖注入）

### 前端基础
- HTML 标签和结构
- CSS 布局（Flexbox、Grid）
- JavaScript 基础语法
- Vue 3 入门（组件、响应式数据、模板语法）

### 数据库基础
- 关系型数据库概念（表、字段、主键、外键）
- SQL 基本查询（SELECT、INSERT、UPDATE、DELETE）
- SQLAlchemy ORM 入门

## 第三阶段：AI/LLM 应用开发（2-3 个月）

### 大模型基础概念
- 什么是 LLM（大语言模型）
- Token 是什么（文本被切分成的最小单元）
- Prompt 是什么（给模型的指令/提示词）
- 什么是上下文窗口（模型一次能处理的最大文本量）
- 主流模型了解：GPT、通义千问、文心一言等

### LangChain 框架
- LangChain 是什么（LLM 应用开发框架）
- Chain（链）：把多个步骤串联起来
- Document Loader：加载不同格式的文档
- Text Splitter：文档切分成小片段
- Vector Store：向量数据库的增删查
- Retriever：从知识库中检索相关内容
- Prompt Template：结构化的提示词模板

### Embedding 和向量检索
- 什么是 Embedding（文本→数字向量，表示语义）
- 为什么需要向量检索（理解意思，不只是匹配关键词）
- ChromaDB 的使用
- 余弦相似度计算
- 混合检索（向量 + 关键词）

### RAG 系统实战
- 搭建完整的 RAG 项目（本项目）
- 文档处理流程（加载→切分→向量化→存储）
- 检索流程（查询向量化→搜索→返回文档）
- 生成流程（Prompt 组装→LLM 生成→流式输出）
- 前后端联调
- 部署和测试

## 学习方法论

1. **项目驱动学习**：不只看书看视频，动手做真实项目
2. **写文档写注释**：理解一个概念后，用自己的话写下来
3. **从报错中学习**：遇到 bug 不逃避，研究错误信息、查文档、看源码
4. **建立知识体系**：用思维导图连接不同知识点
5. **定期复盘总结**：每周回顾学了什么，哪些理解了、哪些还需要巩固
