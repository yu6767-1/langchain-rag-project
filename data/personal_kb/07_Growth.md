# 成长经历

## 转行背景

我并非计算机专业科班出身。大学学的是其他专业，毕业后发现自己对技术和 AI 更感兴趣，于是决定自学转行。

## 为什么选择 AI 方向

1. **AI 是未来趋势**：大模型的出现让 AI 应用的门槛大幅降低
2. **兴趣驱动**：和 AI 对话、让 AI 帮自己查资料，这个过程本身就很有趣
3. **实用价值**：AI 可以真正解决实际问题（如企业知识管理、客服问答等）
4. **入门友好**：相比底层算法研究，AI 应用开发对数学基础要求较低

## 学习中的困难

### 困难一：概念爆炸

刚开始学习时，每天都会遇到大量新概念：LLM、RAG、Embedding、向量数据库、Prompt、Token、Chunk……每个概念背后都有复杂的原理。

**应对方法**：每学一个新概念，就用"是什么、为什么、怎么用"三个问题来理解，然后用生活类比加深记忆。

### 困难二：调试之苦

一个 bug 可能卡一整天。最怕的不是报错，而是"没报错但表现不对"。

**应对方法**：学会用 print/console.log 追踪数据流；学会读错误信息；学会用浏览器 DevTools 和 Postman 测试 API。

### 困难三：技术选型

Python 还是 Node.js？FastAPI 还是 Flask？Vue 还是 React？LangChain 还是 LlamaIndex？

**应对方法**：先选一个开始，不用追求完美。理解了核心概念后，技术栈的切换成本不高。

## 最重要的转变

**从"看教程"到"做项目"**：看十遍教程不如动手做一遍。我这个 RAG 项目就是从零开始一行行写出来的，过程中踩了无数坑，但每个坑都让我学到了新东西。

**从"背代码"到"理解原理"**：不再死记硬背 API 用法，而是理解设计思想。比如理解了 Repository 模式后，就知道为什么要把数据访问和业务逻辑分开。

**从"怕报错"到"主动测试"**：以前怕看到红色报错信息，现在会主动写单元测试、主动制造边界条件来验证代码的健壮性。

## 我的优势

1. **学习能力强**：从零到独立开发全栈 AI 应用，证明了我的自学能力
2. **动手能力强**：不满足于"看懂了"，一定要"做出来"
3. **问题解决能力**：遇到 bug 不放弃，能系统性地排查和解决
4. **技术热情**：发自内心地喜欢 AI 技术，不是"为了找工作而学"
5. **零基础视角**：因为自己从零学起，更懂得如何让技术变得易懂

## 我的不足

1. **计算机基础理论薄弱**：数据结构、算法、操作系统等科班基础还需要补
2. **英文技术文档阅读速度**：需要提升，目前依赖翻译工具
3. **生产环境经验不足**：项目目前只在本地运行，缺乏部署和运维经验
4. **团队协作经验少**：主要是独立开发，缺乏 Git 协作、Code Review 等团队经验
